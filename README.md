# Student Marks Analyzer 📊

## About the Project

Student Marks Analyzer is a simple Python project that analyzes the marks of a student in five subjects.

The program calculates the total marks, average marks, highest mark, lowest mark, and grade.

## Features

* Enter student name
* Enter marks for 5 subjects
* Calculate total marks
* Calculate average marks
* Find highest mark
* Find lowest mark
* Calculate grade

## Technologies Used

* Python

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:


python student_marks_analyzer.py

## Example
===== Student Marks Analyzer =====

Enter student name: Sai
Enter marks for Subject 1: 85
Enter marks for Subject 2: 90
Enter marks for Subject 3: 78
Enter marks for Subject 4: 88
Enter marks for Subject 5: 92

===== Student Result =====
Student Name: Sai
Total Marks: 433.0
Average: 86.6
Highest Mark: 92.0
Lowest Mark: 78.0
Grade: A
